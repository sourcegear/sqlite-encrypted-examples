# SQLite.Encrypted example applications

These applications demonstrate the official SQLite.Encrypted packages in realistic, idiomatic projects. Each example requires a licensed SQLite Encryption Extension (SEE) activation key.

Free fully-featured demo keys are available from [sqlite.sourcegear.com](https://sqlite.sourcegear.com/#evaluation).

| Example | Package |
| --- | --- |
| [Encrypted Expo Field Journal](https://github.com/sourcegear/sqlite-encrypted-expo-field-journal) | `@sqlite-encrypted/expo` |
| [React Native Offline Inventory](https://github.com/sourcegear/sqlite-encrypted-react-native-inventory) | `@sqlite-encrypted/react-native` |
| [Capacitor Encrypted Service Log](https://github.com/sourcegear/sqlite-encrypted-capacitor-service-log) | `@sqlite-encrypted/cordova` |
| [Cordova Encrypted Equipment Checkout](https://github.com/sourcegear/sqlite-encrypted-cordova-equipment-checkout) | `@sqlite-encrypted/cordova` |
| [Node.js Encrypted Local Task Service](https://github.com/sourcegear/sqlite-encrypted-node-task-service) | `@sqlite-encrypted/node` |
| [Encrypted Flutter Expense Tracker](https://github.com/sourcegear/sqlite-encrypted-flutter-expense-tracker) | `sqlite_encrypted` |
| [Encrypted Room Notes](https://github.com/sourcegear/sqlite-encrypted-android-room-notes) | `org.sqlite.encrypted:sqlite3` |
| [SwiftUI Private Contacts](https://github.com/sourcegear/sqlite-encrypted-swiftui-private-contacts) | `SQLiteEncrypted` |
